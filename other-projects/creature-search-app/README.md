## This project dealt with APIs, Promises and fetching data

In this project, I applied my knowledge of APIs and Promises to make an app that fetches data from an external source using try-catch statements and asynchronous coding concepts and manipulated the data to be displayed nicely on the page. I am particularly proud of this project, not because it was a hard challenge that I overcame but because I think the code is very robust, readable and clean.
